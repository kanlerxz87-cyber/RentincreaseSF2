Integration credit and method

This review was produced across several cooperating sessions and is tracked in COORDINATION.md in the repository. The occupancy, algorithmic-pricing, licensing-consequence and retaliation findings were identified by the parallel session that authored pull request #5; that branch shares no git ancestor with main, so its findings were re-verified against the primary sources above and re-implemented here rather than merged. Automated checks run on every push: scripts/sync_nav.py (one canonical navigation), scripts/validate_site.py (internal links, official-source allowlist, a source link on every table row, column integrity, privacy sweep) and scripts/verify_calculations.py (every dollar amount and deadline re-derived from the official percentages). sf.gov — 571 table; Civ.
