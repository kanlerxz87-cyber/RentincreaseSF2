F-23 — Privacy: tenant initials remain in this repository's git history

Found and fixed in the published files. An earlier session quoted the six supplied tenant initial pairs inside COORDINATION.md while reviewing a different pull request. Because GitHub Pages serves the repository root, that Markdown file was publicly retrievable at the site URL. The initials were redacted from the live file at that time. A later residual audit nevertheless found separate tenant-specific matching examples in public code and the audit; those have now been removed under F-36. What is still outstanding. This repository is public, and redaction only changes the current version. The earlier commits still contain the initials and remain reachable through the repository's history. No page on this site displays them, and no current file contains them, but history is a separate exposure.

Options for the owner to decide. (1) Make the repository private — GitHub Pages access control depends on the plan, so check the effect on the live site first. (2) Rewrite history to remove the string and force-push, which is destructive and would discard other sessions' commit identities, so it was deliberately not done automatically. (3) Document and accept the residual exposure after assessing the privacy risk. This is the owner's call, not an automated one.
